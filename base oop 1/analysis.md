# Анализ предметной области — Библиотечная система (Задание 1)

## 1.

Cуществительные, претендующие на роль класса:

- **Book (Книга)** — Явная сущность, имеет идентичность (ISBN), состояние.
- **Reader / User (Читатель)** — Упоминается в тексте («читатели», «люди, которые берут книги»), но заказчик говорит «мы их пока не различаем» — кандидат, но пока без атрибутов.
- **Library (Библиотека)** — Не названа прямо, но подразумевается как контейнер: «список всех книг», «выдать/вернуть».
- **ISBN** — Атрибут книги, не сущность.
- **Автор** — Атрибут книги, не сущность на этом этапе.
- **Название** — Атрибут книги.
- **Полка** — Место хранения, это скорее состояние, чем сущность.
- **Ошибка** — Не сущность, а сигнал. 

## 2. 

### Book (Книга)

**Знает (атрибуты):**
- `isbn` — уникальный номер (string)
- `author` — автор (string)
- `title` — название (string)
- `isAvailable` / `isIssued` — доступна ли сейчас (boolean)

**Умеет (поведение):**
- сообщить свои данные 
- изменить состояние на «выдана»
- изменить состояние на «доступна»
- сообщить, доступна ли она

### Library (Библиотека)

**Знает (атрибуты):**
- `books` — коллекция всех книг (список/множество)

**Умеет (поведение):**
- добавить книгу в фонд
- выдать книгу читателю (по ISBN)
- принять возврат книги (по ISBN)
- показать список всех книг
- показать список доступных книг
- показать список выданных книг

### User (Читатель) — кандидат, пока не вводим

**Знает:** (пока ничего — «мы их не различаем»)
**Умеет:** брать книгу, возвращать книгу

## 3. Инварианты 

1. **Книга не может быть одновременно выдана и доступна.** Состояние — ровно одно из двух.
2. **ISBN уникален в пределах фонда библиотеки.** Двух книг с одинаковым ISBN быть не может.
3. **Нельзя выдать книгу, которая уже выдана.** Попытка — ошибка.
4. **Нельзя вернуть книгу, которая не была выдана** Ошибка.
5. **Выданная книга «принадлежит» ровно одному читателю** Просто факт выдачи.
6. **Список всех книг = список доступных ∪ список выданных**, Пересечение пусто.
